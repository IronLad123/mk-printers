## 📱 Google Chrome & PWA Installation

This web application is configured as a standalone **Progressive Web App (PWA)**:
* **Google Chrome (Desktop):** Click the **Install App** icon in the Chrome URL bar to install the web portal directly onto macOS/Windows.
* **Google Chrome (Mobile / Android):** Tap **Add to Home Screen** to install as a full-screen mobile app.
* **Offline Support:** Powered by a lightweight Service Worker (`sw.js`) that caches core styles, fonts, and brand assets.
